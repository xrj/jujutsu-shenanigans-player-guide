# 关卡 4 提交素材｜Jujutsu Shenanigans Player Guide

本文件夹用于生财航海关卡 4 的提交，不是线上站点本身。素材对应的本地站点目录是同级的 `jujutsu-shenanigans-guide/`。

## 文件夹内容

- `图片/首页-本地浏览器.png`：本地首页，包含站点首屏、主导航和三张入口卡片。
- `图片/Guide-新手路线.png`：点击 `Guide` 后的内页截图。
- `图片/Controls-操作说明.png`：点击 `Controls` 后的内页截图。
- `截图清单.md`：每张图的页面地址、证明内容和上传顺序。
- `关卡4-可粘贴文字.md`：提交表单中的复盘感悟与补充说明，可直接复制。
- `来源与操作记录.md`：截图时间、浏览器地址、代码范围和安全排除项。
- `仓库截图/`：GitHub 仓库推送完成后放真实仓库文件列表截图；当前不能用本地文件冒充 GitHub 截图。

## 安全边界

- 不上传 `相关api.txt`、SERPAPI/API Key、Cookie、MCP 配置、浏览器个人信息或命令行密钥。
- 本地截图保留 `127.0.0.1` 的真实环境，不把本地地址包装成线上域名。
- GitHub 仓库截图必须来自实际 GitHub 页面；如果没有目标仓库或推送失败，不生成伪造截图。
