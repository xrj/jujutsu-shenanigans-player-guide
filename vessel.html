Vessel: verify before you build a combo

The community-maintained Vessel Wiki page is the reference for this route. It connects Vessel with Yuji/Sukuna inspiration and lists character details that can help players decide what to test in-game.

Use the page as a map, not a permanent patch note

Community pages can be excellent at collecting names and feature history, but their exact values may lag behind the live game. Before putting any move detail into a published guide, check whether the page has an outdated warning and compare it with the current game or a recent first-party announcement.

A safe practice loop

  1. Open the character in the current game.
  2. Compare the visible move labels with the research page.
  3. Practice one interaction at a time in a safe session.
  4. Record the game version or date when you write notes.
Why no copied combo list? A fixed combo list would create a false promise if a balance change has landed. This coursework build keeps the page useful by showing the research path and the validation step.
