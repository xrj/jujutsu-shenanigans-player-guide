Skill Builder: find it, then verify it

The community Wiki’s Skill Builder page describes a Build Mode feature and an entry route through custom options or character configuration. The source itself carries an outdated warning, so this page intentionally teaches a verification flow rather than presenting the path as permanent.

Use the source in three steps

  1. Read the Wiki page to understand the feature vocabulary.
  2. Open the current game and follow the closest visible menu path.
  3. If labels differ, check the update context and record the difference before sharing instructions.

When a player needs an example

Use a dated gameplay video as a demonstration source and label it with its upload date. Videos are helpful for visual orientation, but they are not proof that a menu or skill still behaves the same way today.

Workshop is a separate question

The Workshop page is a separate community reference. Do not merge sharing/export instructions into a basic Skill Builder guide unless the current game confirms both are available.
